# WiFi密码查询工具使用说明

## 工具简介

WiFi密码查询工具是一个基于Windows批处理的实用程序，可以帮助用户快速查看已保存的WiFi网络密码。该工具支持自动识别系统语言（中文/英文界面），动态匹配 21 种语言的 netsh 输出，操作简单，安全可靠。详见 [语言支持说明.md](语言支持说明.md)。

## 功能特点

### 基础功能
- ✅ 显示所有已保存的WiFi配置（带序号，紧凑格式）
- ✅ 支持序号快速选择，无需手动输入WiFi名称
- ✅ 支持直接输入WiFi名称查询
- ✅ 查询指定WiFi网络的密码
- ✅ 自动将密码复制到剪贴板
- ✅ 自动识别系统语言（v3.0），也支持命令行强制指定（`zh`/`en`/`ja` 等）
- ✅ 动态匹配 netsh 多语言输出关键词（21 种语言，详见 [语言支持说明.md](语言支持说明.md)）
- ✅ 安全的本地运行，不上传任何信息

### 导出功能
- ✅ 批量导出WiFi密码：支持自选导出范围（全部/指定编号）和格式（TXT/CSV）
- ✅ 复制WiFi连接字符串（`WIFI:T:WPA;S:ssid;P:password;;` 格式，手机相机扫码即可连接）
- ✅ 导出进度条实时显示（`█░` 10 段 + 百分比）
- ✅ CSV 文件含 UTF-8 BOM，Excel 打开中文不乱码

### 界面优化
- ✅ 密码显示/隐藏切换（主菜单选项 4）
- ✅ 查询历史记录（最多 10 条，支持序号快速重查）
- ✅ 快捷键提示栏（`[e]导出 [h]历史 [q]退出`）
- ✅ ANSI 颜色高亮（标题青色、WiFi名称黄色、密码亮白、错误红色、成功绿色）
- ✅ Unicode 分隔线（`─`）替代 `====`，视觉更清爽

## 系统要求

- Windows 10/11（推荐，ANSI 颜色需要 VT 支持）
- Windows 7/8（基本功能可用，颜色可能不显示）
- 管理员权限（必需）
- 已连接或曾经连接过的WiFi网络

## 安装和使用

### 1. 下载文件

下载以下文件到您的桌面：
- `wifi_password_tool_auto.bat`（v3.0 统一版，自动识别语言）

### 2. 运行工具

**重要：必须以管理员身份运行！**

**方法一：右键运行**
1. 右键点击 `wifi_password_tool_auto.bat`
2. 选择"以管理员身份运行"

**方法二：命令行运行**
1. 按 `Win + R` 打开运行对话框
2. 输入 `cmd` 并按住 `Ctrl + Shift` 再按回车（以管理员身份打开命令提示符）
3. 切换到脚本所在目录：
   ```
   cd C:\Users\您的用户名\Desktop
   ```
4. 运行脚本：
   ```
   wifi_password_tool_auto.bat
   ```
   也可强制指定语言：
   ```
   wifi_password_tool_auto.bat zh
   wifi_password_tool_auto.bat en
   ```

## 操作步骤

### 步骤1：启动工具
以管理员身份运行脚本后，工具会显示：
- 当前系统中所有已保存的WiFi配置列表（带有序号，紧凑格式）
- 快捷键提示栏：`[e]导出  [h]历史  [q]退出  [/关键词]模糊搜索  [序号/名称]查询`
- 输入提示：`请输入序号或WiFi名称查询密码（e导出，q退出，/关键词模糊搜索）：`

WiFi列表显示示例：
```
  [用户配置文件]
  ---------------------------------
    01. CMCC-NPxe-5G
    02. HomeinnSelected
    03. Redmi 8A
    04. JinJiangRewards
   ...
    18. TPGuest_3006
```

### 步骤2：选择WiFi
有四种方式：

**方式一：输入序号（推荐）**
- 直接输入对应的序号，例如输入 `3` 选择第3个WiFi

**方式二：输入WiFi名称**
- 输入完整的WiFi名称（区分大小写）

**方式三：模糊搜索（`/关键词`）**
- WiFi 列表很长？用 `/` 触发模糊搜索，例如：
  - `/home` → 列出所有包含 `home` 的 WiFi（如 HomeWiFi-5G、home_office）
  - `/xana 5g` → 多关键词 AND，列出同时包含 `xana` 和 `5g` 的 WiFi
  - 大小写无关，子串匹配；输入序号选中，或回车取消

**方式四：快捷键**
- `e` = 批量导出WiFi密码
- `h` = 查看查询历史记录
- `q` = 退出程序

### 步骤3：查看结果
工具会显示：
```
────────────────────────────────────────────
  WiFi名称: [您选择的WiFi名称]（黄色高亮）
  WiFi密码: [实际密码]（亮白色高亮）
  密码强度: 强 [█████]  ← 新增：基于长度/字符类/黑名单评分
────────────────────────────────────────────

  [OK] [密码已复制到剪贴板]
```

**密码强度评分规则**（0-5 分）：
- 长度 ≥12 加 2 分；≥8 加 1 分；<8 减 1 分
- 字符类型（大小写/数字/特殊）≥3 加 2 分；=2 加 1 分
- 黑名单口令（如 `12345678`、`password`、`qwerty` 等 29 项）减 4 分
- 包含 SSID 子串减 2 分
- 含 `1234`/`abcd` 等连续 4 字符减 2 分
- 含 3+ 重复字符（如 `aaa`）减 1 分
- 0-1 分：弱（红色）；2-3 分：中等（黄色）；4-5 分：强（绿色）
- 切换显示/隐藏密码后，强度条会一并隐藏（看不见没法评分）

### 步骤4：主菜单操作
查询完成后，主菜单提供 6 个选项：
```
  1) 继续查询其他WiFi
  2) 导出当前WiFi密码
  3) 复制WiFi连接字符串（手机扫码）
  4) 显示/隐藏密码 (R)
  5) 查看查询历史 (H)
  6) 退出程序
```

- 选项 4 可切换密码的显示/隐藏状态（隐藏时显示 `********`）
- 选项 5 可查看最近 10 条查询记录，输入序号快速重新查询

### 步骤5：批量导出（可选）
在主界面输入 `e` 可进入批量导出流程：

1. **选择导出范围**：
   - `1` 导出所有 WiFi 配置
   - `2` 导出指定编号的 WiFi 配置（输入编号，多个用逗号分隔，如 `1,3,5`）
   - `0` 取消

2. **选择导出格式**：
   - `1` 导出为 TXT 文本文件
   - `2` 导出为 CSV 文件（含 UTF-8 BOM，Excel 兼容）
   - `0` 取消

3. **导出过程**：实时显示进度条
   ```
   [██████░░░░] 60% HomeinnSelected  ->  Home@2024
   ```

4. **导出完成**：显示文件位置和统计信息

**TXT文件内容示例**：
```
────────────────────────────────────────────
               WiFi密码批量导出报告
────────────────────────────────────────────

导出时间: 2026/09/17  10:30:00
导出工具: WiFi Password Query Tool v3.0
WiFi总数: 18

────────────────────────────────────────────
序号   WiFi名称                              WiFi密码
────────────────────────────────────────────
 1.  CMCC-NPxe-5G                          P@ssw0rd123
 2.  HomeinnSelected                        Home@2024
 ...
────────────────────────────────────────────
导出统计: 成功 17 / 无密码 1 / 总计 18
────────────────────────────────────────────
```

**CSV文件内容示例**：
```
序号,WiFi名称,WiFi密码

2,HomeinnSelected,Home@2024
...
```

## 常见问题解答

### Q1: 为什么需要管理员权限？
A: WiFi密码信息存储在系统安全区域，只有管理员权限才能访问这些信息。

### Q2: 提示"[ERROR] 找不到该WiFi配置文件！"怎么办？
A: 请检查：
- 如果使用序号选择，确保序号在有效范围内
- 如果输入WiFi名称，确认名称是否正确（区分大小写）
- 该WiFi是否曾经连接过并保存了密码

### Q3: 密码显示为空怎么办？
A: 可能的原因：
- 该WiFi没有保存密码（如开放网络）
- 密码已过期或被系统清除
- 网络配置异常

### Q4: ANSI 颜色不显示或乱码怎么办？
A: 
- 确保使用 Windows 10+ 终端
- 确保终端支持 VT（Virtual Terminal）处理
- 确保终端使用 UTF-8 编码（脚本已自动执行 `chcp 65001`）

### Q5: 导出的文件保存在哪里？
A: 导出文件保存在脚本所在目录，文件名格式：
- TXT: `WiFi密码导出_YYYY-MM-DD_HH-MM-SS.txt`
- CSV: `WiFi密码导出_YYYY-MM-DD_HH-MM-SS.csv`

### Q6: 如何在非中文系统上使用？
A: 脚本自动识别系统语言。也可强制指定：`wifi_password_tool_auto.bat en`（英文）、`wifi_password_tool_auto.bat zh`（中文）等。

## 错误信息说明

| 错误信息 | 原因 | 解决方法 |
|---------|------|----------|
| [ERROR] 请以管理员身份运行此脚本！ | 权限不足 | 右键选择"以管理员身份运行" |
| [ERROR] 没有输入WiFi名称！ | 空输入 | 输入有效的序号/WiFi名称，或q退出，或e导出 |
| [ERROR] 找不到该WiFi配置文件！ | WiFi名称/序号错误或不存在 | 检查序号是否在范围内，或WiFi名称是否正确 |
| [ERROR] 无法获取密码信息 | 密码获取失败 | 该WiFi可能没有保存密码 |
| [ERROR] 当前没有可导出的WiFi配置！ | 系统中没有任何WiFi配置 | 先连接并保存至少一个WiFi |
| [ERROR] 未选择有效的编号！ | 导出时输入的编号无效 | 输入有效序号（逗号分隔，如 1,3,5） |
